# Pax Aeterna

Pax Aeterna ist ein Echtzeit-Weltraumstrategiespiel von SeBBos chaotiKKK Game Studio. Baue planetare Werften, entwirf Schiffe, erforsche neue Systeme und erteile Flottenbefehle auf der Galaxie- oder Systemkarte.

Die spielbaren Dateien stehen unter [Releases](https://github.com/chaotiKKK/pax-aeterna/releases). Jede Ausgabe enthält ein Windows-ZIP, eine Android-APK und SHA-256-Prüfsummen.

- **Windows.** ZIP vollständig in einen eigenen Ordner entpacken und `PaxAeterna.exe` starten. Linksklick wählt aus, Rechtsklick erteilt Befehle.
- **Android.** Die signierte APK enthält die Spieldaten und unterstützt ARM64 sowie x86_64. Antippen wählt ein Schiff aus. Halte das Ziel bis zur Eingabe eines Befehls und lass los. Ziehen dreht die Ansicht, zwei Finger zoomen.
- **LAN.** Beide Spieler verwenden dieselbe Ausgabe. Gib im Multiplayer-Menü die lokale IP-Adresse des Hosts ein.

Das öffentliche Paket verwendet projekteigene Planeten- und Stationsmodelle sowie den Studio-Schriftzug. Interface- und Sci-Fi-Sounds stammen aus zwei CC0-Paketen von Kenney.
